# Map image attribution

The two regional map images are static exports of Esri's World Dark Gray Canvas
Base and Reference services, covering the forecast's 200 × 200 km footprint.
They are third-party cartographic content. Copyright © 2026 Esri and its licensors.
All rights reserved.

Sources: Esri, HERE, Garmin, © OpenStreetMap contributors, and the GIS user community.

- [Esri terms and attribution for static maps](https://doc.arcgis.com/en/arcgis-online/reference/static-maps.htm)
- [OpenStreetMap copyright and attribution](https://www.openstreetmap.org/copyright)

`map_manifest.json` records the export URLs, map projection, bounds, and image
checksums. The images are packaged so forecasts can be rendered offline. Every
generated forecast PNG displays the source attribution.
